## Overview

An interactive R Shiny application for generating Kaplan-Meier survival curves directly from user-uploaded data. Designed to make survival analysis accessible to clinical researchers without programming experience.

**[View on GitHub](https://github.com/Emomeow/R-shiny)** | **[Live Demo](https://yuezhan.shinyapps.io/KMcurve/)**

## Features

- Upload your own dataset (CSV format)
- Select event time and censoring status columns interactively
- Stratify by one or multiple grouping variables
- Filter data subsets for focused analysis
- Supports interaction terms across combinations of groups
- Publication-ready plot output

## Tools

**R**: shiny, survival, survminer, ggplot2
